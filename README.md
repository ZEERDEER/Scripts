# 🎈 Loon

个人脚本仓库：Loon 插件、脚本、规则。

## 结构

- `Loon/`：Loon 插件与配置
  - `unlock/`：会员解锁（阿里云盘、GitHub、FIMO、Leica、懒人听书、月亮听书、极简汇率、Koco、Duolingo、影视 App）
  - `tools/`：工具（比价、TestFlight、LocalDevVPN、Talkatone、小象超市）
  - `media/`：观影（ScripTV）
  - `adblock/`：去广告（知乎）
  - `icons/`：插件图标
  - `Loon.conf`：Loon 配置
- `js/`：脚本文件
  - `unlock/`：解锁类脚本
  - `checkin/`：签到任务（小象超市、百度贴吧）
  - `media/`：观影（ScripTV）
- `Scriptable/py-scripts/`：Python 脚本（New API 签到、贴吧签到、Telegram 推送）
- `rule/`：分流规则（香港银行）
- `lingoDuo/`：Duolingo 解锁的 Quantumult X / Surge 配套文件
